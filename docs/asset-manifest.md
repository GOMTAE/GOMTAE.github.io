## Inline animation derivatives

`npm run assets:motion` rebuilds `*-loop.mp4` files and generated `assets/portfolio/media/loops.json` from the five original sources above. FFmpeg preserves source frame timing and produces silent H.264 video; no intermediate scientific frames or results are invented. The SSP loop is the existing KD-SSP quadrant, not a newly generated result.

Loops load only when visible, pause offscreen/in background tabs, and provide a persistent pause/play control. Reduced-motion and save-data preferences keep still frames until explicit playback. Original GIF files remain in the repository; the user requested removal of their visible archive links. Publication-index preview images remain stills until the author supplies approved replacement media.

## Publication animation excerpts

Each publication retains only its final silent MP4 for inline playback and a matching WebP fallback poster under `assets/portfolio/media/`. Conversion is reproducible with `scripts/prepare-publication-motion.mjs`; dimensions, durations, source, trim offset and crop are in `publication-loops.json`. The publication previews have no visible controls, stop offscreen, and retain stills for reduced-motion/data-saving preferences. Original source files are unchanged.

- MultiFly: author-supplied `multifly_semantic_clouds.mp4`, seconds 8-23. Crop removes title/legend bands and excess side space to fill the 16:10 frame. The RGB and LiDAR labels are re-anchored inside the crop; existing IR/Radar labels and semantic cloud motion are retained.
- VoxelFix: author-supplied `voxelfix-web.mp4`, seconds 16-20.5. Crop isolates the Scene 2 before/after semantic correction wipe and labels; excludes header, ground-truth reference panel and footer.
- MissionBench: [isolated-house rooftop inspection animation](https://gomtae.github.io/images/MissionBench/mission_webps/CityEnv_isolated_house_rooftop_mission25_TPV.webp), first 15 seconds of the existing project-page animated WebP.
- SSP: existing `publications/static/videos/ssp_banner_video.mp4`, seconds 5-20, cropped to the upper-right KD-SSP output panel. Full four-method comparison remains available from the hero.
- FlexPath: all four original [repository animations](https://github.com/FraunhoferIVI/FlexPath/tree/main/resources): `optimal.gif`, `obstavoidance.gif`, `semavoidance.gif`, `waypoint.gif`. Combined into a labeled 2-by-2 collage, preserving each source's frame timing and repeating each to fill a 15-second loop. Each map omits the bottom 48-pixel border beyond the demonstrated paths; labels occupy the outer left/right rails of a 16:10 frame, with no label strips or gaps between the four maps. Tim Schönbrod and Taehyoung Kim, 2026, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); repository license retained as `flexpath-source-LICENSE.txt`. Changes: composition, labels, resize, re-encoding and poster extraction. No alteration of the search or resulting paths.
