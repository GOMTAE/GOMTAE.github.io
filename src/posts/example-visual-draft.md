## Try adding your own image

1. Select **Editor** above the Article field.
2. Click on an empty line where you want the image.
3. Type `/` and choose **Image**.
4. Choose an image from the library or upload one, then insert it.
5. Add a description of what the image shows.

If GitHub reports a permission error during upload or save, the Pages CMS GitHub connection needs write access to this website repository.
